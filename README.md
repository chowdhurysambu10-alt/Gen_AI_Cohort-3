## ✨ Overview

Personal Gemini Journal is an AI-powered personal journaling application that allows users to securely write journals, brainstorm ideas, and receive intelligent insights generated by Google's Gemini AI.

Unlike traditional AI demos, this application is designed with production-grade security principles including authenticated access, isolated user data, secure secret management, and protected AI endpoints.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/personal-gemini-journal.git
```

Go into the project

```bash
cd personal-gemini-journal/frontend
```

Install dependencies

```bash
npm install
```

Create environment variables

```bash
cp .env.example .env.local
```

Run locally

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env.local`

```env
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=

GOOGLE_SECRET_NAME=
GOOGLE_CLOUD_PROJECT=
```

Never commit secrets.
